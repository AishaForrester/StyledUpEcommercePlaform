About StyledUp

A learning-driven e-commerce project

Project Overview

StyledUp is a full-stack e-commerce web application created as a personal portfolio project. The goal of this project was to design and implement a realistic shopping experience while gaining deeper, hands-on experience with backend web development using Spring Boot.

The application supports product browsing, cart management, checkout, and secure payment processing, while following clean architecture principles and best practices.

About the Developer

I am a final-year Software Engineering student at the University of The West Indies, and StyledUp was built to strengthen my understanding of full-stack application development, particularly within the Java and Spring ecosystem.

This project allowed me to explore real-world challenges such as authentication, database design, secure payments, MVC architecture, and frontend–backend integration.
